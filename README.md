# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Player X and Player O turns
- Winner detection
- Draw detection
- Restart button
- Simple design

## How to Play

1. Open `index.html` in a web browser.
2. Player X starts the game.
3. Players take turns clicking the boxes.
4. The first player to get three symbols in a row wins.
5. Click "Restart Game" to play again.

## Technologies Used

- HTML
- CSS
- JavaScript
